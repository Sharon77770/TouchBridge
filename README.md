# TouchBridge

TouchBridge turns an Android phone into a gesture and custom-button controller for Windows PCs.

TouchBridge는 Android 휴대폰을 Windows PC용 제스처 및 커스텀 버튼 컨트롤러로 사용하는 앱입니다.
